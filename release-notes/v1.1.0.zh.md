### 新功能
- 支持飞书多账号渠道配置，便于在同一环境中管理多个飞书账号或渠道。
- 增强既有 OpenClaw / Gateway 实例的发现与托管能力，升级或恢复时可以更平滑地接管已有运行实例。
- 隔离 Debug Run 与正式安装版运行环境，减少开发调试和正式安装版之间的互相影响。

### 改进与修复
- 优化 Gateway 启动、就绪等待、健康状态和恢复流程，减少误判、卡顿和异常复用运行态的情况。
- 显示初始化准备进度，让启动和恢复过程更清晰。
- 降低模型页、定时任务页等页面触发 OpenClaw 扫描或刷新时对启动性能的影响。
- 固定 OpenClaw 运行时版本，提升打包发布和运行时行为的一致性。
