# 模型配置自动同步 + 智能体独立选模型

## Context

当前状态：用户在「全局模型池」配置 API Key 后，需要手动打开 `ApplyCredentialSheet` 逐个虾同步凭据。智能体的模型选择只是一个文本框，未持久化到 OpenClaw 配置。

目标：
1. **配置完 Key 后自动同步**到所有活跃 Shrimp，无需手动操作
2. **每个智能体可独立选模型**，从已配置的全局模型池中选择，写入 `agents.list[].model.primary`

---

## Feature 1: 自动同步 API Key 到所有 Shrimp

### 1.1 新建 `CredentialSyncService`

**新文件:** `ClawdHome/Services/CredentialSyncService.swift`

```swift
@Observable @MainActor
final class CredentialSyncService {
    private let helperClient: HelperClient
    private let shrimpPool: ShrimpPool
    private let modelStore: GlobalModelStore
    private var pendingTask: Task<Void, Never>?
    
    private(set) var isSyncing = false
    private(set) var lastError: String?
    
    // 带 1 秒防抖的触发入口
    func scheduleSyncAll()
    // 实际同步：遍历 shrimpPool.users 中的标准用户
    func syncAllShrimps() async
    // 单用户同步（复用 ApplyCredentialSheet 的 payload 构建逻辑）
    func syncShrimp(username: String) async throws
}
```

- **Payload 构建**：从 `ApplyCredentialSheet` 提取 `buildSecretsPayload` / `buildAuthProfiles` 逻辑（:254-280），作为 `CredentialSyncService` 的方法
- **防抖**：使用 `Task` + `Task.sleep(1s)` 合并快速连续的变更
- **并行同步**：对多个 Shrimp 用 `withTaskGroup` 并行调用 `helperClient.syncSecrets()`

### 1.2 添加变更回调

**`GlobalSecretsStore.swift`** — 添加 `onDidChange` 闭包：
- 在 `save(entry:)`, `delete(secretKey:)`, `rename(oldKey:newEntry:)` 末尾调用

**`GlobalModelStore.swift`** — 添加 `onDidSave` 闭包：
- 在 `save()` 末尾调用

### 1.3 在 `ClawdHomeApp.swift` 中装配

- 创建 `CredentialSyncService` 实例
- 绑定回调：`modelStore.onDidSave = { syncService.scheduleSyncAll() }`
- 绑定回调：`GlobalSecretsStore.shared.onDidChange = { syncService.scheduleSyncAll() }`
- 注入 `.environment(syncService)` 到各 Window

### 1.4 保留 `ApplyCredentialSheet` 作为手动回退

不修改现有 Sheet，但可选地将 payload 构建重构为调用 `CredentialSyncService` 的共享方法以消除重复。

## Feature 2: 智能体独立选模型

### 2.1 `AgentStore` 增加 `setAgentModel()` 方法

**文件:** `ClawdHome/Services/Stores/AgentStore.swift`

```swift
func setAgentModel(agentId: String, modelId: String?) async throws {
    // 1. configGetFull() 读取当前配置 + baseHash
    // 2. 找到 agents.list[] 中对应 agentId 的条目
    // 3. 设置/清除 entry["model"] = ["primary": modelId]
    // 4. configPatch() 写回
    // 5. 更新本地 agents[idx].preferredModel
}
```

### 2.2 `parseConfig()` 读取 per-agent model

**文件:** `AgentStore.swift:parseConfig()` (:308)

在解析 `agents.list[]` 条目时，增加：
```swift
let modelConfig = entry["model"] as? [String: Any]
let agentModel = modelConfig?["primary"] as? String
// 传入 Agent 初始化：preferredModel: agentModel ?? preset?.preferredModel
```

### 2.3 替换 `AgentSettingsView` 的文本框为 Picker

**文件:** `ClawdHome/Views/Agent/AgentWorkspaceView.swift:334-390`

将 `TextField` 替换为 `Picker`：
- 数据源：`GlobalModelStore.allTemplateModels`（需注入 `@Environment(GlobalModelStore.self)`）
- 首选项 `""` 表示「使用全局默认」
- `onChange(of: preferredModel)` 时调用 `store.setAgentModel()`
- Gateway 未连接时 `.disabled(true)` 并显示提示

### 2.4 替换 `AgentEditorView` 的文本框

**文件:** `ClawdHome/Views/Agent/AgentEditorView.swift:72-79`

同样替换为 Picker，在 `save()` 中调用 `store.setAgentModel()`。

### 2.5 智能体列表/卡片显示所用模型

在智能体卡片（`AgentGridView` 或相关视图）中，显示 `agent.preferredModel ?? "全局默认"` 的 caption 标签。

## 验证方案

1. **自动同步验证**：
   - 在全局模型池中添加/修改一个 Provider 的 API Key
   - 等待 ~1 秒后检查目标 Shrimp 的 `~/.openclaw/secrets.json` 是否已更新
   - 删除一个 Provider，确认同步后 secrets 对应条目已移除

2. **智能体选模型验证**：
   - 进入智能体设置，选择一个模型
   - 通过 WebSocket 或 `openclaw config get agents.list` 确认 `model.primary` 已写入
   - 重启 Gateway 后确认该智能体使用指定模型
   - 选择「使用全局默认」，确认 `model` 键被清除

3. **边界情况**：
   - Gateway 未连接时，Picker 应 disabled 并提示
   - 快速连续修改多个 Key，应只触发一次同步（防抖）
   - 没有任何 Shrimp 用户时，同步静默跳过
