# 新建智能体向导（Create Agent Wizard）

## Context

当前 `CreateAgentSheet` 是一个简单的 Form 表单（模板选择 + ID + 基本信息），体验较为简陋。需要改造为截图所示的 **5 步向导式 Modal**，包含模板选择、身份与模型配置、工具开关、技能开关、用户信息填写，提升创建体验的完整度和引导感。

## 步骤详细设计

### Step 0 — 选择起点

- `LazyVGrid`，列宽 `GridItem(.adaptive(minimum: 150, maximum: 200))`
- 每张卡片：RoundedRectangle + emoji + 名称 + 一行描述
- 第一张为"空白智能体"（`+` 图标）
- 选中卡片加 accent 描边
- 数据源：`AgentStore.presetTemplates` + 硬编码的空白选项
- 选中模板后预填后续步骤字段（name/emoji/description/category/skills）

### Step 1 — 身份与模型

- **左面板**（~60%）：
  - 名称 TextField
  - 头像区：预设 emoji 横向滚动 + "上传自定义" 按钮（暂用 emoji 选择）
  - 描述 TextEditor（2-4 行）
  - 风格标签：`FlowLayout` / 自动换行 HStack，可多选 chip
  - 模型供应商：chip 组（自动 / Gemini / Qwen / OpenAI / Claude / Moonshot / Zhipu / MiniMax），单选
- **右面板**（~40%）：
  - `WizardAgentPreviewCard`：实时显示头像、名称、"身份已验证"徽章、描述、风格
  - 从 `CreateAgentWizardState` 响应式读取

### Step 2 — 工具（占位）

- 8 个工具分类，每组一行：图标 + 名称 + 子工具列表文字 + Toggle
- 默认全部开启
- 底部可选"默认工作区"选择器
- **纯 UI，不接后端**，Toggle 状态仅存在 wizardState 中

### Step 3 — 技能

- 列表行：emoji + 名称 + 描述 + Toggle
- 数据源优先从 `GatewaySkillsStore` 获取真实技能列表
- 若网关不可用，显示截图中的静态列表（技能搜索/技能创建/自我进化/Gmail/MCP/演示文稿）
- 选中的技能 key 写入 `Agent.skills`

### Step 4 — 用户信息

- 如何称呼你（TextField）
- 偏好语言（Picker: 中文/English/日本語）
- 备注（TextField，单行）
- 补充背景（TextEditor，3-5 行）
- 数据在提交时组装为 USER.md seed content

## 状态管理

一个 `@Observable` 类 `CreateAgentWizardState` 持有全部向导数据：

```swift
@Observable final class CreateAgentWizardState {
    var currentStep: Int = 0          // 0-4
    // Step 0
    var selectedTemplateId: String?
    // Step 1
    var agentId: String = ""          // 自动从 name 生成，高级可手动改
    var name: String = ""
    var emoji: String = "🤖"
    var description: String = ""
    var category: AgentCategory = .strategy
    var selectedStyles: Set<String> = []
    var selectedProvider: String?     // nil = 自动
    // Step 2
    var enabledToolCategories: Set<String> = Set(AgentToolCategory.all.map(\.id))
    // Step 3
    var enabledSkills: Set<String> = []
    // Step 4
    var userDisplayName: String = ""
    var preferredLanguage: String = "中文"
    var userNotes: String = ""
    var userBackground: String = ""
    // Submission
    var isCreating = false
    var errorMessage: String?
}
```

在 `CreateAgentWizardView` 中用 `@State` 持有，传给子 step view 作为参数。

## 数据流（提交时）

1. **验证**：agentId 非空且不重复、name 非空
2. **组装 seed content**：
   - 若选了模板 → 从 `PresetAgents.json` 提取 systemPrompt/identity/userTemplate 作为基础
   - 用向导数据覆盖/追加：
     - `IDENTITY.md` ← 名称 + 描述 + 风格标签
     - `USER.md` ← 称呼 + 语言 + 备注 + 背景
     - `SOUL.md` ← 模板的 systemPrompt（若有）
3. **调用** `store.addAgent(id:name:emoji:description:category:fromPresetId:seedContent:preferredModel:skills:)`
4. 成功则 dismiss，失败显示错误

### AgentStore.addAgent 扩展

```swift
func addAgent(
    ...,                                       // 现有参数
    seedContent: [PersonaFile: String]? = nil,  // 新增：预组装 seed
    preferredModel: String? = nil,              // 新增
    skills: [String]? = nil                     // 新增
) async throws
```

若 `seedContent` 非 nil，直接使用而非从 `fromPresetId` 提取。

- 在 Step 1 以"高级选项" DisclosureGroup 暴露可编辑 ID 字段
- 降低用户操作门槛

## UI 规范

- 窗口尺寸：`.frame(minWidth: 720, minHeight: 580)`
- 进度条：线性百分比条 + "第 X/4 步" / "完成 N%" 文字
- 底部导航栏：HStack，左侧"取消"/"上一步"，右侧"下一步：XXX"/"完成并启动"
- 遵循项目现有样式：
  - 卡片：`.background(Color(nsColor: .controlBackgroundColor))` + `.clipShape(RoundedRectangle(cornerRadius: 10))` + subtle border
  - 按钮：`.borderedProminent`（主按钮）、`.bordered`（次按钮）
  - 字号：标题 18pt bold、正文 13pt、caption 11pt
- 所有文案用 `L10n.k()` 包裹

## 实施顺序

1. 新建 `AgentStyle.swift`、`AgentToolCategory.swift`（模型/数据定义）
2. 新建 `CreateAgentWizardState.swift`（状态类）
3. 新建 `CreateAgentWizardView.swift`（向导外壳：进度条 + 步骤切换 + 底部导航）
4. 依次实现 Step 0 → Step 1（含 PreviewCard）→ Step 2 → Step 3 → Step 4
5. 改造 `CreateAgentSheet.swift` 为薄包装层
6. 扩展 `AgentStore.addAgent()` 签名
7. 接通提交逻辑（seed content 组装 + 调用 addAgent）
8. 确保新文件加入 Xcode 项目（xcodegen generate）
9. `make build` 编译验证
